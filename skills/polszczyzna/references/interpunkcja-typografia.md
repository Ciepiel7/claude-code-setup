# Interpunkcja i typografia

Format: `źle → dobrze — dlaczego — źródło`. Źródło zbiorcze przecinka: https://sjp.pwn.pl/zasady/Przecinek;629769.html

Wiem że masz rację → Wiem, że masz rację — zdanie podrzędne
Strona która sprzedaje → Strona, która sprzedaje — zdanie względne
Piszę aby zapytać → Piszę, aby zapytać — cel
Zadzwonię gdy skończymy → Zadzwonię, gdy skończymy
Nie działa bo wtyczka → Nie działa, bo wtyczka
Zrobimy to co ustaliliśmy → Zrobimy to, co ustaliliśmy
Szybki, jak rakieta → Szybki jak rakieta — porównanie bez czasownika
Tańszy, niż Shopify → Tańszy niż Shopify — porównanie bez czasownika
Taniej niż zakładaliśmy → Taniej, niż zakładaliśmy — po „niż” czasownik, więc przecinek
Zobaczysz jak rośnie → Zobaczysz, jak rośnie — „jak” wprowadza zdanie

Punkty-zdania: wielka litera, kropka na końcu każdego.
Punkty z wewnętrznymi przecinkami: między punktami średnik. — https://sjp.pwn.pl/poradnia/haslo/Interpunkcja-w-wyliczeniach;74.html
